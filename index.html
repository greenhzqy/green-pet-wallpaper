关于
GREEN
陪伴精灵
v1.0

一个住在你电脑里的绿色氢原子。它看得见你在忙什么，在你坐太久时递一句话， 把深水区的慢反馈翻译成你系统认得的快反馈。没有账号，没有上传，数据不出这台机器。

谁做的 · 什么时候

氢之卡比

2026 年 9 月，从一颗只会在屏幕上转圈的绿球开始。

技术栈

  • 零依赖 Node 服务 · server.js · 127.0.0.1:8765
  • three.js r160（UMD）+ 纯手写 CSS
  • 没有一个前端框架，没有构建步骤
  • 手绘 SVG 图标与滤镜；数据只躺在一个 7KB 的 state.json 里

设计原则

  • 不用 emoji —— 每一枚图标都是自己画的线。
  • 弹簧动效 —— 走 var(--spring) 的过冲曲线，不用 CSS 默认缓动。
  • 无感陪伴 —— 不弹窗催你，只在你抬头的时候递一句。
  • 过渡只写在隐藏态 —— 被节流的窗口里，过渡不推进，写反了元素会永远卡在半透明。
